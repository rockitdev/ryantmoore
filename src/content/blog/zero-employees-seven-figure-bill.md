> Before you hand your work to an agent, run one sum: the value of the outcome, minus what the model costs to produce it, minus what it costs you when it gets one wrong. If that is not comfortably positive, the agent is a luxury, not a saving.

Ben Cera's company Polsia has become the poster child for the zero-employee business. By his own account it scaled to an eight-figure annual run rate with no staff, run by an agent that wakes each night and picks the next thing to do. It is a real company and, as far as anyone outside can tell, a real number.

Here is the figure that belongs next to it. In a single month, Polsia's model bill reportedly ran into seven figures, somewhere around a million and a half dollars. Tasks Ben priced at a dollar sometimes cost thirty to fifty in model fees behind the scenes. The work ran while he slept, and it spent real money every time it woke up, enough that in a heavy month the bill can rival the revenue it is chasing.

That is the part worth sitting with. This is not a machine that quietly saves money in the background. It is a very capable worker you rent by usage, and the meter is most of the story.

## The sum that decides it

Skip the technology and do one piece of arithmetic before you automate anything:

> value of the outcome − model cost to produce it − cost when it gets one wrong

If that comes out comfortably positive, hand it over. If it is thin, or you are unsure, keep it manual a while longer. Polsia works because a night of agent decisions is worth more than the night's bill. Plenty of tasks are not, and the only way to know is to price both sides.

## Not everything that repeats needs an agent

There is a cheaper trap here too. A lot of the work people reach for an agent to do does not need one. If a task is the same every time, with clear rules and no judgment, plain automation does it for a fraction of the cost and never surprises you. Sending a receipt, moving a file, posting a reminder: that is a scheduled job, not a thinking machine.

Save the agent for work that genuinely needs a decision, and use dumb, reliable automation for the rest. Paying model fees to do something a simple rule could handle is how the bill creeps up with nothing to show for it.

## Where the agent earns it

The jobs worth a real agent share two traits: they need a judgment call, and getting that call wrong costs real money. Qualifying a lead and deciding where to route it. Reading a messy support request and deciding whether it can be answered or needs a person. Work where the thinking is worth paying for, and where a mistake is expensive enough to justify the review step you will want around it.

## The honest read

The zero-employee business is real, and so is the knife-edge it runs on. When your biggest bill is the thing doing the work, a good month and a bad month look very different, and "let the agent handle it" stops being free advice.

That is not a reason to stay away. It is a reason to do the sum first. The agent is worth it exactly when the outcome clears the meter, and the whole skill is knowing, task by task, whether it does.
